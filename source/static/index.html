Connexion

Le plus simple : ouvrir le logiciel avec l'icône Transcription Vidéo du Bureau, qui connecte automatiquement.

Sinon, colle le jeton d'accès : la ligne API_TOKEN=… du fichier .env (64 caractères, sans API_TOKEN=). Pour l'afficher : grep API_TOKEN .env.
